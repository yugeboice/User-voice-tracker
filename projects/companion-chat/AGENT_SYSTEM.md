# 🤖 Agent系统使用说明

## ✅ 已实现功能

### 1. Agent驱动的多轮对话
- **自动激活**: 当你提问时，系统会根据关键词自动选择并激活合适的Agent
- **持续会话**: Agent会在整个对话过程中保持激活状态，直到任务完成
- **多轮交互**: Agent可以多次与你对话，收集详细需求

### 2. 智能决策系统
Agent会分析每条用户输入并决定：
- **是否需要搜索**: 判断当前任务是否需要网络调研
- **生成搜索词**: 如果需要搜索，自动生成1-3个精准关键词
- **直接回答**: 如果信息足够，直接提供专业建议

### 3. Agent工作流程

```
用户: "我想做AA产品市场调研"
  ↓
系统: 检测到"市场调研"关键词 → 激活Agent
  ↓
Agent: [第1轮] "好的！为了帮你做好AA产品的市场调研，我需要了解：
        1. AA产品的具体类型是什么？
        2. 目标用户群体？
        3. 主要竞品有哪些？"
  ↓
用户: [回答Agent问题]
  ↓
Agent: [第2轮] 分析需求 → 决策: needSearch=true
       搜索词: ["AA产品市场规模", "AA产品竞品分析", "AA产品用户需求"]
  ↓
系统: 并行搜索3个query → 获取最新市场数据
  ↓
Agent: [第3轮] 基于搜索结果生成调研报告
       "📊 根据最新市场数据，为您整理了AA产品调研报告：
        
        一、市场规模
        [来源1] ...
        
        二、竞品分析
        [来源2] ...
        
        三、用户需求
        [来源3] ...
        
        💡 下一步建议：是否需要我生成PPT？"
  ↓
用户: "是的，生成PPT"
  ↓
Agent: [第4轮] "好的，我将基于调研数据生成PPT大纲..."
       💾 *已保存到知识库: conversation_xxx.md*
       
       任务完成 ✅
```

## 🔧 Agent匹配规则

系统会根据关键词自动选择Agent：

| 关键词 | 激活的Agent | 功能 |
|--------|------------|------|
| PPT、幻灯片、演示文稿、汇报 | PPT Agent | 专注PPT生成 |
| 产品、设计、开发、项目、需求 | CLAUDE Agent | 团队协调者 |
| 市场、调研、竞品、分析 | RESEARCH Agent | 市场研究 |
| 数据、统计、图表 | DATA Agent | 数据分析 |

## 💡 Agent特性

### 1. 上下文记忆
- Agent会记住整个对话历史（最多10轮）
- 后续提问会基于之前的上下文

### 2. 智能搜索决策
- Agent会判断何时需要搜索
- 不是每次都搜索，避免浪费资源
- 搜索时会生成精准的关键词

### 3. 多轮引导
- Agent会主动提问收集信息
- 引导你完成完整的任务流程
- 明确标注任务完成状态

### 4. 自动保存
- 有价值的调研报告自动保存
- 保存为Markdown格式
- 可在知识库中查看

## 📝 技术实现

### 后端流程
1. **会话检测**: 首次提问时根据关键词选择Agent
2. **会话保持**: Agent会话持续到任务完成
3. **决策分析**: 每轮对话Agent都会分析是否需要搜索
4. **结果生成**: 基于搜索结果+历史对话生成回答

### 关键代码
- `SmartChatService.ProcessWithAgentAsync()` - Agent处理流程
- `SmartChatService.AgentAnalyzeAsync()` - Agent决策分析
- `SmartChatService.AgentGenerateResponseAsync()` - Agent生成回答
- `LocalKnowledgeService.SelectAgentByIntentAsync()` - Agent智能选择
