# 🚀 快速开始 - AI 智能聊天功能

## 一键启动

1. **启动应用**
   ```bash
   cd Lumina-API-Demo
   dotnet run
   ```

2. **打开浏览器**
   - 访问: http://localhost:8400

3. **开始聊天**
   - 登录 Microsoft 账号
   - 在"💬 AI 智能聊天"框中输入问题
   - 等待AI基于网络搜索生成回答

## API 接口说明

### POST /api/chat

**请求体:**
```json
{
  "question": "用户的问题",
  "topN": 5
}
```

**响应:**
```json
{
  "answer": "AI生成的回答（基于网络搜索结果）",
  "timestamp": "2024-01-29T10:30:00Z"
}
```

**流程:**
1. 接收用户问题
2. 调用 SearchApi 搜索网络（topN条结果）
3. 将搜索结果传递给 LlmExample
4. LLM 生成基于搜索结果的回答
5. 返回回答给前端

## 测试建议

### 适合的问题类型
✅ 需要最新信息的问题（新闻、天气、股价等）  
✅ 事实性问题（历史事件、科学知识等）  
✅ 比较和分析问题（产品对比、技术选型等）  
✅ 操作指南问题（怎么做XXX）  

### 不太适合的问题类型
❌ 纯创意写作（诗歌、故事等）  
❌ 个人隐私相关问题  
❌ 需要登录才能访问的内容  
❌ 实时交互类任务（需要多轮确认的操作）  

## 故障排查

### 问题 1: 登录失败
**解决方案:**
- 检查 `appsettings.json` 中的 Azure AD 配置
- 确保 TenantId 和 ClientId 正确
- 检查网络连接

### 问题 2: AI 回复很慢
**原因:**
- 搜索需要时间（通常2-5秒）
- LLM生成需要时间（通常3-10秒）

**正常响应时间:** 5-15秒

### 问题 3: 回答不准确
**可能原因:**
- 搜索结果质量不佳
- 问题表述不够清晰

**建议:**
- 使用更具体的问题
- 增加关键词
- 指定时间范围

### 问题 4: 出现错误提示
**检查清单:**
- [ ] Lumina API 配置正确
- [ ] Copilot API 运行在 localhost:4141
- [ ] 网络连接正常
- [ ] 已成功登录
