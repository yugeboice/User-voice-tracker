# 📊 PPT自动生成功能说明

## ✅ 已集成功能

### 1. 智能PPT生成
系统已完全集成PPT自动生成功能，支持：
- **从Markdown自动生成**: 将AI回答转换为PowerPoint幻灯片
- **智能内容解析**: 自动识别标题、内容、列表
- **自动保存**: PPT保存到知识库目录
- **一键下载**: 生成后自动下载到本地

### 2. 两种使用方式

#### 方式一：直接在对话中生成（推荐）
```
你: 帮我做智能手表的市场调研，并生成PPT

Agent: 
[进行市场调研搜索...]
[生成调研报告...]

📊 **PPT已生成！**
文件名: 智能手表市场调研_20260130_143025.pptx
位置: C:\knowledge\智能手表市场调研_20260130_143025.pptx
💡 提示: PPT已保存到知识库目录，可以直接打开查看！
```

关键词触发：包含"生成PPT"、"做PPT"、"生成幻灯片"、"PPT"时自动生成

#### 方式二：使用UI按钮生成
1. 获得AI的详细回答（搜索结果或长文本）
2. 点击输入框旁的 **📊 生成PPT** 按钮
3. 系统自动将最后一条回答生成PPT
4. 自动下载到浏览器下载文件夹

## 📝 PPT生成规则

### 内容解析
系统会自动解析Markdown格式：

```markdown
# 智能手表市场调研报告
↓ 生成为封面幻灯片

## 市场规模分析
↓ 生成为内容幻灯片标题

• 2025年全球市场达500亿美元
• 中国市场占比35%
↓ 生成为幻灯片内容（自动添加项目符号）
```

### 幻灯片结构
1. **封面幻灯片**: 一级标题（#）
2. **内容幻灯片**: 二级标题（##）+ 内容
3. **自动清理**: 移除Markdown标记（**、*、`、[]()等）
4. **项目符号**: 自动为内容添加 • 符号

## 🔧 技术实现

### 后端架构
```csharp
PptGeneratorService (OpenXML库)
├── GenerateFromMarkdown() - 从Markdown生成
├── GenerateFromData() - 从结构化数据生成
├── ParseMarkdownToSlides() - 解析Markdown
├── CreatePowerPoint() - 创建PPT文件
├── CreateTitleSlide() - 创建封面
└── CreateContentSlide() - 创建内容页
```

### API端点
- `POST /api/ppt/generate` - 生成PPT
- `GET /api/ppt/download/{fileName}` - 下载PPT

### 前端功能
- `generatePptFromLastAnswer()` - 从最后答案生成
- `📊 生成PPT` 按钮 - 显示在有长回答时
- 自动下载机制

## 📊 PPT格式特性

### 设计规范
- **封面**: 大标题（44pt粗体）+ 副标题（24pt）
- **内容页**: 标题（32pt粗体）+ 内容（18pt）
- **项目符号**: 自动添加 • 符号
- **文本框**: 自动适配内容长度
- **中文支持**: Language="zh-CN"

### 文件命名
格式: `{标题}_{时间戳}.pptx`
- 示例: `市场调研报告_20260130_143025.pptx`
- 自动清理非法字符
- 限制长度50字符

### 保存位置
1. **优先**: 知识库路径（如已设置）
2. **备选**: `%TEMP%\LuminaPPT\`

## 🔍 故障排查

### PPT按钮不显示
- 确保开启了智能模式
- 确保AI回答包含搜索结果或长文本（>500字符）
- 刷新页面重试

### PPT生成失败
- 检查知识库路径是否有写入权限
- 查看浏览器Console错误信息
- 检查后端日志

### PPT打不开
- 确保使用Office 2007或更高版本
- 或使用WPS、LibreOffice等兼容软件
- 检查文件是否完整下载
